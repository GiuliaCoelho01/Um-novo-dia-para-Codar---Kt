# Um-novo-dia-para-Codar---Kt
Estruturas de Dados: Arrays na Prática 🚀
Este repositório contém exercícios práticos em Kotlin para treinar a lógica de programação e manipulação de Arrays e Listas Mutáveis através de interações no terminal.

📝 Desafios
1. Cadastro de Estudantes: Sistema de inserção contínua em uma lista até o usuário acionar o comando de parada, exibindo um relatório final.

2. Planetas do Sistema Solar: Busca e validação de dados: verifica se o nome digitado existe dentro de um array pré-definido.

3. Gerenciador de Compras: Remoção dinâmica de itens. O usuário "compra" frutas de um array, com validação de itens inexistentes e parada automática ao esvaziar a lista.

4. Agenda de Contatos: Sistema CRUD completo em memória usando data classes. Permite adicionar, buscar, listar e remover contatos (nome e telefone).

💻 Tecnologias Aplicadas
Kotlin, Arrays, MutableList, Laços de Repetição (while, for), Condicionais e POO básica.
